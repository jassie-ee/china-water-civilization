# 小澜已接收素材检查（第一批）

## 已具备

以下部件均为 32 位 RGBA PNG，透明通道正常；主体素材长边约 1300 px，可用于网页端 Live2D 贴图：

| 用户说明 | Live2D 图层建议 | 结论 |
| --- | --- | --- |
| 不带遮挡的原型 | `00_reference_front` | 仅对齐参考；320 × 273，不能作为正式贴图 |
| 斗篷 | `10_cape_back`、`11_cape_front` | 可用；图中包含两段需要在 Cubism 中分层处理的水流/斗篷 |
| 身体 | `20_body_base` | 可用 |
| 头 | `30_head_base` | 可用作头部基础 |
| 右腿 | `40_leg_R` | 可用 |
| 右手 | `41_arm_R` | 可用 |
| 左手 | `42_arm_L` | 可用 |
| 左腿 | `43_leg_L` | 可用 |
| 完整形象 | `99_reference_composite` | 仅对齐参考；256 × 216，不能作为正式贴图 |

## 可立即制作的首版效果

在现有素材基础上，可以先实现：

- 全身呼吸与轻微上下浮动；
- 头部、身体和手脚的独立倾斜；
- 拖动时的惯性与斗篷/水流摆动；
- 点击时轻微前倾和抬手；
- `happy`、`thinking`、`turbid` 三种整体动作节奏。

## 缺失的必要面部图层

目前头部将双眼、眉毛、嘴巴和脸部合在同一张图中，因此无法实现真正的 Live2D 面部交互。请从原画或 PSD 继续提供：

```text
face_base（移除双眼、眉毛、嘴巴后的脸部，并补全遮挡区）
eye_L_white / eye_L_iris / eye_L_upper_lid / eye_L_lower_lid
eye_R_white / eye_R_iris / eye_R_upper_lid / eye_R_lower_lid
brow_L / brow_R
mouth_base / mouth_open（或单独口腔、上唇、下唇）
```

如能继续拆分，以下图层会进一步改善质感：前景高光、脸颊腮红、云纹额饰、前后两组水流、衣领和胸前挂饰。

## 第二批补充

已收到空白五官的 `face_base`。它与完整形象的画幅比例一致，已用于网页端分层预览：以 `face_base` 作为底图，再从完整形象中以遮罩回填左右眼和嘴巴。该预览用于验证层级和对齐；真正的 Cubism 模型仍应以单独且干净的眼睛、眼皮和嘴巴 ArtMesh 绑定。

## 对齐要求

下一批 PNG 请使用与头部相同的原始画布和坐标，不要只按内容裁切；这使 Cubism 导入后可以直接重合。若只能提供裁切图，也可以使用完整形象作为参照重新摆位，但需要额外校准。
