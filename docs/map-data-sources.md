### 调查结论与当前停止点

- 中国轮廓必须继续以带审图号的自然资源部标准地图为国家版图依据；目前没有发现一个同时满足“完整国家版图、可直接发布派生 SVG、坐标系明确”的官方下载资产。现有 EPS 不能进行可靠语义提取，因此不能生成 `china-outline.svg`。
- 黄河、长江专题候选数据中，国家地球系统科学数据中心的数据来源和主题较匹配，但公开条款不足以确认网页运行时派生资产的再发布/改编权；本项目不能在未取得书面许可的情况下下载并转换。
- HydroSHEDS 的专题数据许可和 WGS 84 坐标信息更公开，但它不具备中国国家版图底图资格；其数据也必须先完成主干流/流域组合规则、许可文本和精度复核，才能作为专题数据候选。
- 因五份资产必须共用一个经过核验的国家版图画布，本阶段不确定最终投影、SVG viewBox，也不创建任何最终 SVG 或预览图。

### 后续统一展示方案（待数据获准后执行）

- 先保留原始矢量文件及其 `.prj` / 元数据；以 GDAL/PROJ 在一个脚本内把全部输入投影到同一展示 CRS，再以统一 bbox 和固定 padding 输出五份 SVG。
- 候选专题数据若采用 WGS 84（EPSG:4326），建议评估以适合中国横向展示的 Lambert Conformal Conic 投影作为网页几何中间坐标；具体中央经线、标准纬线和最终 viewBox 必须由获准的完整国家版图与两条专题数据的联合边界计算得出，不能沿用 EPS 的 `1602.6667 × 1077.3333`。
- 同一转换脚本将固定 `extent`、padding、精度与简化容差，并输出简化前后顶点/要素数及叠加预览，以保证五份 SVG 无拉伸、无相对偏移。
- 第三级黄河专门地图继续独立使用既有 `1400 × 800` viewBox；它服务于流域内部节点布局，不与中国总览坐标绑定。
